### 任务 2：方向约束强化

**核心需求**：传送带经过物流桥格子时只能直线穿过，不能转弯。

**文件**：`lib/AIC/Logistics Units/transport_belt.dart`

#### 2.1 修改 `_findPathBFS()` — 物流桥格子只允许直线通过

在 BFS 中，当扩展到物流桥格子时，只允许沿入方向继续前进（不允许转弯）。

需要修改 BFS 的状态，增加入方向信息。将 `_BFSNode` 从 `(x, y)` 扩展为 `(x, y, incomingDir)`，其中 `incomingDir` 为进入该格子的方向（0=up, 1=right, 2=down, 3=left, -1=起点无方向）。

**修改逻辑**：

```dart
// 在 BFS 扩展时，如果当前格子是物流桥格子，只允许沿入方向继续
if (_findBeltBridgeAtCell(Offset(node.x.toDouble(), node.y.toDouble())) != null) {
  // 物流桥格子：只允许直线通过
  if (node.incomingDir >= 0) {
    // 只扩展入方向相同的方向
    final allowedDir = _bfsDirToOffset[node.incomingDir];
    // ... 只添加 allowedDir 方向的邻居
  }
}
```

**具体实现**：

1. 修改 `_BFSNode` 类：

```dart
class _BFSNode {
  final int x, y;
  final int incomingDir; // 0=up, 1=right, 2=down, 3=left, -1=无
  _BFSNode(this.x, this.y, this.incomingDir);
}
```

1. 修改 `_findPathBFS()` 中的扩展逻辑：

* 当 `node` 位于物流桥格子且 `incomingDir >= 0` 时，只允许沿 `incomingDir` 方向扩展

* 当 `node` 不在物流桥格子上时，正常四方向扩展

* visited key 需要包含方向信息（在物流桥格子处）：`"${nx}_${ny}_$dir"` 以允许不同方向到达同一格子

1. 修改 `_calculateMomentumPath()` — 检测路径是否在物流桥格子处转弯：

* 生成路径后，检查每个物流桥格子的前后方向是否一致

* 如果不一致，标记 momentum path 无效，回退到 BFS

#### 2.2 添加路径验证方法

```dart
/// 验证路径在物流桥格子处是否保持直线
bool _isPathValidAtBridges(List<Offset> path) {
  for (int i = 0; i < path.length; i++) {
    if (_findBeltBridgeAtCell(path[i]) == null) continue;
    // 物流桥格子：前后方向必须一致
    final dirIn = i > 0 ? _directionBetween(path[i - 1], path[i]) : null;
    final dirOut = i < path.length - 1 ? _directionBetween(path[i], path[i + 1]) : null;
    if (dirIn != null && dirOut != null && dirIn != dirOut) {
      return false; // 在物流桥处转弯，路径无效
    }
  }
  return true;
}
```

在 `_findPath()` 中，momentum path 生成后调用此验证，不通过则回退到 BFS。

### 任务 3：修复 `_autoCreateBridgesAtCrossings()` 潜在 bug

**问题**：当一个被交叉的传送带有多个交叉点时，处理第一个交叉点后传送带被移除，后续交叉点引用的索引失效。

**修复方案**：在处理交叉前，按传送带分组收集所有交叉点，然后对每条传送带一次性处理所有交叉点。

```dart
void _autoCreateBridgesAtCrossings() {
  // 1. 收集所有交叉点
  final crossings = <...>[];
  // ... (现有收集逻辑不变)

  if (crossings.isEmpty) return;

  // 2. 按被交叉传送带分组
  final beltCrossings = <ConveyorBelt, List<({Offset cell, int index, String newDir, String beltDir})>>{};
  for (final c in crossings) {
    beltCrossings.putIfAbsent(c.belt, () => []).add(c);
  }

  // 3. 对每条传送带，按索引排序后一次性拆分
  final processedBelts = <ConveyorBelt>{};
  for (final entry in beltCrossings.entries) {
    final oldBelt = entry.key;
    if (processedBelts.contains(oldBelt)) continue;
    processedBelts.add(oldBelt);

    final points = entry.value..sort((a, b) => a.index.compareTo(b.index));

    // 放置物流桥建筑
    for (final p in points) {
      if (_findBeltBridgeAtCell(p.cell) != null) continue;
      final building = getBuilding?.call(_beltBridgeId);
      if (building == null) continue;
      final newBridge = PlacedBuilding(
        id: 'building_${DateTime.now().millisecondsSinceEpoch}',
        building: building,
        gridX: p.cell.dx - (building.gridWidth ~/ 2).toDouble(),
        gridY: p.cell.dy - (building.gridHeight ~/ 2).toDouble(),
        rotation: 0,
      );
      project.buildings.add(newBridge);
    }

    // 拆分传送带
    project.conveyors.remove(oldBelt);
    // 在每个交叉点处拆分，生成多段传送带
    // ... 拆分逻辑
  }
}
```
