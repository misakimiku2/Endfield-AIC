# 仓库取货口/存货口弹窗 — 仓库卡片与轨道背景修改计划

## 概述

修改仓库取货口（DepotUnloaderPanel，输出端）和存货口（DepotLoaderPanel，输入端）设备弹窗：
1. 去掉包裹轨道组件的外层圆角矩形背景（`#1E1E1E` Container）
2. 在物品格左侧增加仓库卡片（265×128，圆角矩形，含仓库图标/物品名/数量/物品图片）
3. 仓库卡片与物品格之间用带端点圆圈的连接线相连（风格同普通设备生产区域）

最终布局：`[仓库卡片 265×128] —连接线 75px— [物品格 128×128] [轨道 168×54]`

#### 改动2b：新增 `DepotWarehouseCard` 组件

在 `depot_grid_tile.dart` 文件内新增此类（不创建新文件）。

**规格**：
- 尺寸：265×128（高度与物品格一致）
- 圆角矩形：`borderRadius: 15`（与物品格一致），边框 `Border.all(color: #7F7F7F, width: 5)`（与物品格描边一致）
- 背景色：`#696969`（与物品格背景一致）
- `clipBehavior: Clip.antiAlias`

**内部布局（Stack）**：

```
┌─────────────────────────────────────────┐
│ 物品名称 (左上角)                        │
│                                         │
│                    [物品图片]            │
│                    (left:80, 原始尺寸)    │
│                                         │
│ [Depot_icon] 99999  (左下角)             │
└─────────────────────────────────────────┘
```

**具体实现**：
```dart
class DepotWarehouseCard extends StatelessWidget {
  final Item? item;
  final bool isInput;

  const DepotWarehouseCard({
    super.key,
    required this.item,
    required this.isInput,
  });

  @override
  Widget build(BuildContext context) {
    final hasItem = item != null;
    final displayName = hasItem ? item!.name : '——';
    final displayQuantity = hasItem ? '99999' : '——';

    return Container(
      width: 265,
      height: 128,
      decoration: BoxDecoration(
        border: Border.all(color: const Color(0xFF7F7F7F), width: 5),
        borderRadius: BorderRadius.circular(15),
        color: const Color(0xFF696969),
      ),
      clipBehavior: Clip.antiAlias,
      child: Stack(
        children: [
          // 左上角：物品名称
          Positioned(
            top: 8,
            left: 10,
            child: Text(
              displayName,
              style: const TextStyle(
                color: Colors.white,
                fontSize: 14,
                fontWeight: FontWeight.w500,
              ),
            ),
          ),
          // 右侧：物品图片（原始像素尺寸，距离左边框80px）
          if (hasItem && item!.imageAssetPath.isNotEmpty)
            Positioned(
              left: 75,  // 80px from outer left edge - 5px border = 75px in Stack
              top: 0,
              bottom: 0,
              child: Center(
                child: Image.asset(
                  item!.imageAssetPath,
                  // 不指定 width/height，使用原始像素尺寸（允许溢出）
                  errorBuilder: (_, __, ___) => const SizedBox.shrink(),
                ),
              ),
            ),
          // 左下角：仓库图标 + 数量
          Positioned(
            bottom: 5,  // 10px from outer bottom edge - 5px border = 5px in Stack
            left: 5,    // 10px from outer left edge - 5px border = 5px in Stack
            child: Row(
              mainAxisSize: MainAxisSize.min,
              children: [
                SvgPicture.asset(
                  'assets/svg/Depot_icon.svg',
                  // 使用 SVG 原始尺寸（约39×34px）
                ),
                const SizedBox(width: 8),
                Text(
                  displayQuantity,
                  style: const TextStyle(
                    color: Colors.white,
                    fontSize: 14,
                    fontWeight: FontWeight.w500,
                  ),
                ),
              ],
            ),
          ),
        ],
      ),
    );
  }
}
```

**关键决策**：
- 物品图片使用 `Image.asset` 不指定 width/height，使用原始像素尺寸（用户确认允许溢出）
- 图片 `Positioned(left: 75)` = 距卡片外左边框 80px（含5px边框）
- 仓库图标 `Positioned(left: 5, bottom: 5)` = 距卡片外左/下边框 10px（含5px边框）
- Depot_icon.svg 使用 `SvgPicture.asset` 不指定尺寸，保持 SVG 原始尺寸（约39×34px）
- 无物品时（item=null）：物品名和数量均显示"——"，不显示物品图片

#### 改动2c：新增 `DepotCardConnector` 连接线组件

在 `depot_grid_tile.dart` 文件内新增此类。

**规格**：
- 尺寸：75×128（75px间距，128px与卡片/物品格等高）
- 水平线：位于垂直中心（y=64），从左到右横跨75px
- 端点圆圈：左右各一个，半径6.0，实心填充
- 颜色：输入侧（isInput=true，存货口）白色 `Colors.white`；输出侧（isInput=false，取货口）金色 `#EBAD26`
- 线条：`strokeWidth=3.0`, `StrokeCap.round`（与普通设备 TrackJointsPainter 一致）

```dart
class DepotCardConnector extends StatelessWidget {
  final bool isInput;

  const DepotCardConnector({super.key, required this.isInput});

  @override
  Widget build(BuildContext context) {
    return SizedBox(
      width: 75,
      height: 128,
      child: CustomPaint(
        painter: DepotCardConnectorPainter(isInput: isInput),
      ),
    );
  }
}

class DepotCardConnectorPainter extends CustomPainter {
  final bool isInput;

  const DepotCardConnectorPainter({required this.isInput});

  @override
  void paint(Canvas canvas, Size size) {
    final color = isInput ? Colors.white : const Color(0xFFEBAD26);

    final linePaint = Paint()
      ..style = PaintingStyle.stroke
      ..strokeWidth = 3.0
      ..strokeCap = StrokeCap.round
      ..color = color;

    final circlePaint = Paint()
      ..style = PaintingStyle.fill
      ..color = color;

    final centerY = size.height / 2;

    // 水平连接线
    canvas.drawLine(Offset(0, centerY), Offset(size.width, centerY), linePaint);

    // 左端点圆圈（靠近仓库卡片）
    canvas.drawCircle(Offset(0, centerY), 6.0, circlePaint);

    // 右端点圆圈（靠近物品格）
    canvas.drawCircle(Offset(size.width, centerY), 6.0, circlePaint);
  }

  @override
  bool shouldRepaint(covariant DepotCardConnectorPainter oldDelegate) {
    return oldDelegate.isInput != isInput;
  }
}
```

## 假设与决策

| 决策点 | 选择 | 原因 |
|---|---|---|
| 物品图片尺寸 | 原始像素尺寸（允许溢出） | 用户明确确认 |
| 存货口仓库卡片物品 | 显示"——"（item=null） | 用户确认，当前无输入物品追踪 |
| 取货口仓库卡片物品 | 使用 selectedItem | 即 selectedOutputItemId 对应的物品 |
| 连接线颜色 | 存货口白色，取货口金色 | 与普通设备 TrackJointsPainter 一致（isInput=true→白，isInput=false→金） |
| 连接线样式 | 3px描边+6.0半径实心圆 | 与普通设备 TrackJointsPainter 一致 |
| 仓库卡片背景色 | `#696969` | 与物品格背景一致 |
| 仓库卡片边框 | `#7F7F7F`, 5px, 圆角15 | 用户要求"颜色与物品格的描边一致" |
| Depot_icon.svg 尺寸 | SVG原始尺寸（约39×34px） | 用户未指定缩放，使用自然尺寸 |
| 物品名/数量字号 | 14px, 白色 | 合理默认值，可后续调整 |
| "轨道整体往右移动" | 通过添加左侧仓库卡片自然实现 | 整体居中后轨道自然右移，无需额外间距 |
| 物品数量 | 固定显示"99999" | 用户要求"当前先设置99999" |
