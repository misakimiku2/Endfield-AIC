# 设备弹窗物品栏修复与优化计划

## 问题分析

### 问题1：网格列表滚动速度偏慢
- **位置**: [building_detail_dialog.dart:397](file:///c:/Users/Misaki/Desktop/git/Endfield/lib/widgets/building_detail_dialog.dart#L397)
- **现状**: `Listener` 的 `onPointerSignal` 中，滚动目标值直接使用 `event.scrollDelta.dy`，未做任何倍率放大
- **方案**: 将 `event.scrollDelta.dy` 乘以 1.5，即 `event.scrollDelta.dy * 1.5`

### 问题2：Tooltip 悬停时无法使用滚轮滚动
- **位置**: [building_detail_dialog.dart:576](file:///c:/Users/Misaki/Desktop/git/Endfield/lib/widgets/building_detail_dialog.dart#L576)
- **根因**: Flutter 的 `Tooltip` 组件在显示时会创建一个 `OverlayEntry`，该浮层位于 `Overlay` 中，层级高于 `Listener` 所在的 widget 树。当鼠标移到 tooltip 文字上时，滚轮事件被 tooltip 的 overlay 拦截，无法传递到下层的 `Listener`
- **方案**: 将 `_ResourceGridTile` 中的 `Tooltip` 替换为自定义 tooltip 实现，使用 `MouseRegion` 检测悬停 + `OverlayEntry` 显示提示，并在 `OverlayEntry` 外层包裹 `IgnorePointer`，使其不拦截任何指针事件（包括滚轮）

### 问题3：底部物品的 Tooltip 超出显示区域
- **位置**: 同上
- **根因**: Flutter `Tooltip` 默认显示在子元素下方，当物品位于网格底部时，tooltip 会出现在容器可视区域之外
- **方案**: 在自定义 tooltip 实现中，根据物品在网格中的位置动态计算 tooltip 的显示方向（上方/下方），确保 tooltip 始终在网格容器的可视范围内

## 实施步骤

### 步骤1：提升滚动速度（1.5倍）
- 修改 `_buildGridArea()` 方法中第397行
- 将 `event.scrollDelta.dy` 改为 `event.scrollDelta.dy * 1.5`

### 步骤2：创建自定义 Tooltip 组件替代 Flutter Tooltip
- 在 `_ResourceGridTile` 中移除 `Tooltip` 包裹
- 改用 `MouseRegion` + 自定义 overlay tooltip 实现：
  - `MouseRegion.onEnter` 时创建 `OverlayEntry`，显示物品名称
  - `MouseRegion.onExit` 时移除 `OverlayEntry`
  - `OverlayEntry` 的 child 包裹 `IgnorePointer`，不拦截任何指针事件
  - tooltip 位置通过 `RenderBox.localToGlobal` 获取物品位置后动态计算
  - 如果物品位于网格下半部分，tooltip 显示在物品上方；否则显示在下方
  - tooltip 样式保持与原 `Tooltip` 一致（深色背景 + 白色文字 + 圆角）

### 步骤3：处理边界情况
- 在 `_ResourceGridTile` 中需要获取网格容器的边界信息来判断 tooltip 方向
- 通过 `BuildContext` 查找网格容器的 `RenderBox`，获取其全局位置和尺寸
- 计算 tooltip 出现位置时，确保不超出网格容器的上边界和下边界
- 在 widget 销毁时（`dispose` 或 `deactivate`）确保移除 overlay entry，防止内存泄漏
