### process（这个是物品转换成产品的过程区域）
- output //这个是输出区域
    - output_track //这个是输出轨道，输出的物品会从这上面从左往右移动。
        - image60 //这个是输出的图片素材，输出图片素材也需要做从左往右的移动动画，频率根据生产时间来定，例如：一个物品生产完成需要2秒，那么两秒之后该图片就会从轨道左侧往右移动，动画速度为1秒，曲线为慢快慢这样的形式，当移动到右方时，输出物品的数量-1
        - path29 //这个是指向右边的三角箭头，需要复制多个，箭头与箭头之间的间隔是50px，做从左往右移动的动画，动画循环方式（无限循环，从轨道外的左侧移动到轨道外的右侧，速度为恒定速度）
        rect29、rect28 //这两个组件组成了输出轨道
    - output_interface_link_separate //这个是输出接口链接分隔线，装饰用
    - output_interface、output_interface_link这两种组件组成了输出接口样式。轨道紧贴在这个接口上
    - Output_window //这个是输出的窗口
        - Output_window_link //这个是连接output_interface_link_separate的东西
        - image1-15 //这个是输出物品的图片素材
        - Output_window_background //这个是输出窗口的背景。输出物品的图片素材放在上面
        - text4 //这个是输出物品的数量
- input //这个是输入区域
    - input_window //这个是输入窗口
        - input_window_link //这个是连接input_interface_link_separate的东西
        - image1-1 //这个是输入物品的图片素材，当传送带输送物品进入时，该物品的图片就会从轨道左侧往右移动，动画速度为1秒，曲线为慢快慢这样的形式，当移动到右方时，输入物品的数量+1
        - input_window_background //这个是输入窗口的背景。输入物品的图片素材放在上面
        - text3 //这个是输入物品的数量
    - input_interface_link_separate //这个是输入接口链接分隔线，装饰用
    - input_interface、input_interface_link //这两种组件组成了输入接口样式。轨道紧贴在这个接口上，这些组件的后方都有对应的序号
    - input_track //这个是输入轨道，输出的物品会从这上面从左往右移动
        - image59 //这个是输入的图片素材。
        - path13 //这个是指向右边的三角箭头，需要复制多个，箭头与箭头之间的间隔是50px，做从左往右移动的动画
        - rect12、rect11 //这两个组件组成了输入轨道
- Directional_Animation //设备加工状态指示器，三个箭头依次闪烁（透明度 20% → 60% → 100% 循环）表示设备正在加工的状态。设备启动时才播放
