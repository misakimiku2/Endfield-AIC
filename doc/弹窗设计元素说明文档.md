## 弹窗设计.svg设计稿组件说明

### Inventory_Window（这个是库存物品的窗口）
> 物品数据 在doc\终末地资源列表 - 自然资源.csv、doc\终末地资源列表 - 工业产物.csv中可以找到。对应的图片素材在assets\png\AIC Products、assets\png\Natural Resources这两个文件中可以找到，图片的文件名对应着csv文件里的英文ID
- scrollbar //这个是页面的上下滚动条，滚动条的滚动范围、起始位置与Content_area_mask的高度一致。当列表显示不完全的时候才会显示滚动条，一次性渲染所有物品，然后用 CSS 滚动
- Tab_bar //这个是顶部标签
    - Mineral_Ore_icon、Plant_icon、Products_icon //是标签页类型的按钮
    - tab_switch_button //是切换按钮，当切换到别的标签页时，这个按钮会移动到对应的标签按钮上。并切换下方的物品栏里的物品类型内容
    - rect48 //是标签模块的底部背景
- objective_list//这个是物品列表，物品以每行4个的数量进行网格的排布
    - image //这个是库存物品的图片素材
    - objective_case //这个是物品网格的底部背景，物品的图片素材放在上面
        - rect42 //这个是网格
        - grid_tag //这个是网格的标签
- Content_area_mask //这个是物品列表的显示范围遮罩，
- Inventory_Window_background //这个是整个Inventory_Window的背景

### process（这个是物品转换成产品的过程区域）
- output //这个是输出区域
    - output_track //这个是输出轨道，输出的物品会从这上面从左往右移动。
        - image60 //这个是输出的图片素材，输出图片素材也需要做从左往右的移动动画，频率根据生产时间来定，例如：一个物品生产完成需要2秒，那么两秒之后该图片就会从轨道左侧往右移动，动画速度为1秒，曲线为慢快慢这样的形式，当移动到右方时，输出物品的数量-1
        - path29 //这个是指向右边的三角箭头，需要复制多个，箭头与箭头之间的间隔是50px，做从左往右移动的动画，动画循环方式（无限循环，从轨道外的左侧移动到轨道外的右侧，速度为恒定速度）
        rect29、rect28 //这两个组件组成了输出轨道
    - output_interface_link_separate //这个是输出接口链接分隔线，装饰用
    - output_interface、output_interface_link这两种组件组成了输出接口样式。轨道紧贴在这个接口上
    - Output_window //这个是输出的窗口
        - Output_window_link //这个是连接output_interface_link_separate的东西
        - image1-15 //这个是输出物品的图片素材
        - Output_window_background //这个是输出窗口的背景。输出物品的图片素材放在上面
        - text4 //这个是输出物品的数量
- input //这个是输入区域
    - input_window //这个是输入窗口
        - input_window_link //这个是连接input_interface_link_separate的东西
        - image1-1 //这个是输入物品的图片素材，当传送带输送物品进入时，该物品的图片就会从轨道左侧往右移动，动画速度为1秒，曲线为慢快慢这样的形式，当移动到右方时，输入物品的数量+1
        - input_window_background //这个是输入窗口的背景。输入物品的图片素材放在上面
        - text3 //这个是输入物品的数量
    - input_interface_link_separate //这个是输入接口链接分隔线，装饰用
    - input_interface、input_interface_link //这两种组件组成了输入接口样式。轨道紧贴在这个接口上，这些组件的后方都有对应的序号
    - input_track //这个是输入轨道，输出的物品会从这上面从左往右移动
        - image59 //这个是输入的图片素材。
        - path13 //这个是指向右边的三角箭头，需要复制多个，箭头与箭头之间的间隔是50px，做从左往右移动的动画
        - rect12、rect11 //这两个组件组成了输入轨道
- Directional_Animation //设备加工状态指示器，三个箭头依次闪烁（透明度 20% → 60% → 100% 循环）表示设备正在加工的状态。设备启动时才播放

### Task_information（这个是任务信息区域）
- text59 //这个会显示当前设备正在自动生产的配方，当正在生产时显示“当前自动生产中的配方”，如果没有正在生产的内容，则不显示，这个文字会在rect7的上方
- text17 //这个是当前正在生产配方所需要的时间
- path17、path16、path15 //这三个是任务生产过程中的动画组件，箭头会依次从左往右进行20%、60%、100%的透明度动画，当进行生产时，这个动画无限循环播放
- image15 //这个是输出物品的图片素材
- image14 //这个是输入物品的图片素材
- information //这个是任务信息的区域背景以及按钮
    - Recipe_button //这个是可以查询当前设备能够生产的物品按钮，点击后会打开一个新弹窗，上面会显示该设备能够生产的物品类型，物品类型可在doc\终末地资源列表 - 工业产物.csv中看到
    - rect7 //这个是任务信息区域的背景
### unit_switch（这个是设备的开关按钮）
- text34、text33 //开关文字的显示
- toggle_button //切换按钮，当切换开关时，这个按钮会移动过去
- Switch_button_background //这个是开关按钮的背景
### operation（这个是操作按钮区域）
- recycle //这个是收纳按钮，左边是图标，右边是文字，点击后即可收纳设备
- Move //这个是移动按钮，点击后即可对设备进行移动操作
### window_information（这个是窗口信息）
- Close_button //这个是关闭窗口按钮
- path35、path34 //这个是分隔线，用来分隔设备logo、设备名、设备功耗信息
- text2 //这个是设备的功耗信息
- text1 //这个是设备名显示信息
- unit_logo //这个是设备的logo，这个logo可以在每个设备对应的SVG元素中获取到，元素名叫“logo”
- path1 //这个窗口信息和下方内容区域的分隔线
### Collect_button（这个是收取按钮，点击后会清空输出的产品数量）
### path160（这是一个巨大的装饰logo，在窗口的右下角，背景的上方，窗口背景作为该logo的蒙版）
### BG（这个是窗口背景）
