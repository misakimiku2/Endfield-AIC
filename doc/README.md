## 阅读建议

- **初次接触项目**：按 01 → 02 → 03 → 04 顺序阅读，建立全局观。
- **理解运行时行为**：重点阅读 05（交互）与 06（仿真）。
- **理解物流系统**：重点阅读 08（传送带系统），这是项目最复杂的模块。
- **修改 UI 弹窗**：直接查阅 09。
- **查找跨模块依赖**：查阅 10。

## 项目快速信息

- **项目名称**：`endfield_aic_planner`
- **版本**：1.0.0
- **框架**：Flutter (Dart SDK ≥ 3.1.0)
- **核心依赖**：`provider`、`vector_math`、`flutter_svg`
- **代码规范**：`flutter_lints` + 自定义规则（const 优先、单引号、禁 print）
- **目标平台**：桌面/Web（含 Isolate 与 Web 主线程回退两套仿真路径）
