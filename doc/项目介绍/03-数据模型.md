# 03 — 数据模型层

> 对应目录：`lib/models/`

模型层分为两类：
- **元数据模型**（不可变）：`Building`、`Item`、`Recipe`，仅提供 `fromJson` 工厂构造，描述游戏静态数据。
- **运行时状态模型**（可变）：`ProjectState` 及其聚合的 `PlacedBuilding`、`ConveyorBelt`、`ConveyorItemSegment`、`PortState`，是整个项目的状态中枢。

## 3.1 模块依赖关系

```
building.dart                item.dart           recipe.dart
   |                            |                    |
   |  PortDefinition            Item                 RecipeIO
   |  PortsLayout                                    Recipe
   |  Building
   |     ^
   |     |  (import 'building.dart')
   v     |
project.dart
   ├── PortState ────── uses ──► PortDefinition (from building.dart)
   ├── PlacedBuilding ─ uses ──► Building, PortState, ConveyorBelt
   ├── ConveyorItemSegment
   ├── ConveyorBelt ─── uses ──► ConveyorItemSegment
   └── ProjectState ─── uses ──► PlacedBuilding, ConveyorBelt
```

**关键观察**：
1. `building.dart`、`item.dart`、`recipe.dart` 三者相互独立，均为不可变元数据模型。
2. `project.dart` 是唯一包含可变运行时状态的文件，且是唯一显式 `import` 其他 model 文件（`building.dart`）的文件。
3. `PlacedBuilding.activeRecipeId` 与 `Recipe.id` 通过字符串 ID 间接关联（弱耦合），运行时由上层逻辑解析。
4. `PlacedBuilding.inputItemId` / `outputItems` 的键、`ConveyorBelt.itemId` 等均以 `String` 形式引用 `Item.id`，同样未直接 import `item.dart`。

## 3.2 `building.dart` — 建筑元数据

定义工厂建造系统中"建筑"的静态元数据，包括建筑占地、颜色、端口布局、功耗等属性。

### `PortDefinition`

描述建筑上单个端口（输入或输出）的相对位置、方向与类型。

| 字段 | 类型 | 说明 |
|------|------|------|
| `relativeX` | `double` | 端口在建筑网格内的相对 X 坐标（0~1） |
| `relativeY` | `double` | 端口在建筑网格内的相对 Y 坐标（0~1） |
| `direction` | `String` | 端口朝向（`up`/`down`/`left`/`right`） |
| `portType` | `String` | 端口类型，默认 `'solid'`，可为 `'liquid'` |

**方法**：
- `const PortDefinition({required relativeX, required relativeY, required direction, portType = 'solid'})`
- `factory PortDefinition.fromJson(Map<String, dynamic> json)` — 解析 `relative_x`、`relative_y`、`direction`、`port_type`（缺省 `'solid'`）

### `PortsLayout`

聚合一个建筑的所有输入端口和输出端口定义。

| 字段 | 类型 | 说明 |
|------|------|------|
| `inputs` | `List<PortDefinition>` | 输入端口定义列表 |
| `outputs` | `List<PortDefinition>` | 输出端口定义列表 |

**方法**：
- `const PortsLayout({required inputs, required outputs})`
- `factory PortsLayout.fromJson(Map<String, dynamic> json)` — 嵌套解析 `inputs`/`outputs`

### `Building`

描述一种建筑类型的不可变元数据。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `String` | 建筑唯一标识 |
| `name` | `String` | 建筑显示名称 |
| `gridWidth` | `int` | 建筑占用的网格宽度 |
| `gridHeight` | `int` | 建筑占用的网格高度 |
| `color` | `Color` | 建筑颜色（由 hex 字符串解析） |
| `category` | `String` | 建筑分类 |
| `maxInputs` | `int` | 最大输入端口数 |
| `maxOutputs` | `int` | 最大输出端口数 |
| `ports` | `PortsLayout` | 端口布局定义 |
| `powerConsumption` | `double` | 功耗（默认 0） |
| `svgAssetPath` | `String` | SVG 资源路径（默认空） |
| `logoAssetPath` | `String` | Logo 资源路径（默认空） |

**方法**：
- `const Building({...})`
- `factory Building.fromJson(Map<String, dynamic> json)` — 将 hex 颜色字符串（如 `#RRGGBB`）解析为 `Color.fromARGB(255, r, g, b)`，嵌套解析 `PortsLayout`

## 3.3 `item.dart` — 物品元数据

定义游戏中"物品"（资源/产品）的静态元数据。

### `Item`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `String` | 物品唯一标识 |
| `name` | `String` | 物品显示名称 |
| `category` | `String` | 物品主分类（`mineral_ore`/`plant`/`usable`/`product`） |
| `subType` | `String` | 物品子类型 |
| `color` | `Color` | 物品颜色（由 hex 解析） |
| `iconSvg` | `String` | 物品图标的 SVG 内容/路径（缺省 `''`） |
| `imageAssetPath` | `String` | 物品图片资源路径（缺省 `''`） |
| `level` | `int` | 物品等级（缺省 `1`） |

**方法**：
- `const Item({...})`
- `factory Item.fromJson(Map<String, dynamic> json)` — 解析 `id`、`name`、`category`、`sub_type`、`color`（hex 转 `Color`）、`icon_svg`、`image_asset_path`、`level`

## 3.4 `recipe.dart` — 配方元数据

定义生产配方的数据模型，描述某配方允许在哪些建筑中执行、加工时间、输入/输出物品及数量。

### `RecipeIO`

描述配方中单个输入或输出条目。

| 字段 | 类型 | 说明 |
|------|------|------|
| `itemId` | `String` | 物品 ID |
| `amount` | `int` | 数量 |

**方法**：
- `const RecipeIO({required itemId, required amount})`
- `factory RecipeIO.fromJson(Map<String, dynamic> json)` — 解析 `item_id`、`amount`
- `Map<String, dynamic> toJson()` — 序列化

### `Recipe`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `String` | 配方唯一 ID |
| `name` | `String` | 配方名称（从 JSON 解析时会移除 `'精炼'` 字样） |
| `allowedBuildings` | `List<String>` | 允许执行该配方的建筑 ID 列表 |
| `processTimeSeconds` | `double` | 加工时间（秒） |
| `inputs` | `List<RecipeIO>` | 输入物品列表 |
| `outputs` | `List<RecipeIO>` | 输出物品列表 |

**方法**：
- `const Recipe({...})`
- `factory Recipe.fromJson(Map<String, dynamic> json)` — `name` 会执行 `.replaceAll('精炼', '')`；`process_time_seconds` 转 `double`
- `Map<String, dynamic> toJson()` — 序列化（含嵌套 `inputs`/`outputs`）

## 3.5 `project.dart` — 项目运行时状态（核心）

定义工厂布局项目的运行时状态模型，是项目中最复杂、最核心的状态文件。

### `PortState`

表示已放置建筑上一个端口的运行时状态。

| 字段 | 类型 | 说明 |
|------|------|------|
| `index` | `int` | 端口在所属列表中的索引 |
| `type` | `String` | 端口类型：`'input'` 或 `'output'` |
| `definition` | `PortDefinition` | 对应的端口定义 |
| `connected` | `bool` | 是否已连接（默认 `false`） |
| `linkedItemId` | `String?` | 该端口当前关联的物品 ID（可空） |

**关键方法**：
- `Offset worldPosition(double gridX, double gridY, double cellSize, int gridWidth, int gridHeight, {int rotation = 0})` — 根据建筑网格位置、尺寸、旋转计算端口的**世界像素坐标**（含 0°/90°/180°/270° 旋转矩阵变换）
- `Offset gridPosition(double gridX, double gridY, int gridWidth, int gridHeight, {int rotation = 0})` — 同上，但返回**网格坐标**（向下取整）

### `PlacedBuilding`

表示已放置在网格上的建筑实例。

**常量**：
| 常量 | 值 | 说明 |
|------|----|------|
| `maxInputItemCount` | 50 | 输入物品最大缓存数 |
| `maxOutputItemCount` | 50 | 输出物品最大缓存数 |
| `maxBridgeLaneItemCount` | 1 | 物流桥通道容量（设为 1 以快速反压） |
| `_beltBridgeId` | `'belt_bridge_1x1'` | 物流桥建筑 ID |
| `_bridgeLanePrefix` | `'__bridge_lane__'` | 物流桥通道键前缀 |

**字段**：
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `String` | 实例唯一 ID |
| `building` | `Building` | 引用的建筑元数据 |
| `gridX` / `gridY` | `double` | 网格坐标（可变） |
| `rotation` | `int` | 旋转角度（0/1/2/3，对应 0°/90°/180°/270°） |
| `activeRecipeId` | `String?` | 当前激活的配方 ID |
| `depotOutputItemId` | `String?` | 仓库取货口输出物品 ID |
| `inputItemId` | `String?` | 当前输入物品 ID |
| `inputItemCount` | `int` | 输入物品缓存数量 |
| `outputItems` | `Map<String, int>` | 输出物品缓存（itemId → 数量） |
| `inputPorts` / `outputPorts` | `List<PortState>` | 端口运行时状态列表 |
| `isBlocked` | `bool` | 是否被阻塞 |
| `productionProgress` | `double` | 生产进度（0~1） |
| `isPaused` | `bool` | 是否暂停 |

**关键方法**：
- `int get totalOutputCount` — 输出物品总数量
- `bool canAcceptOutputItem(String itemId)` / `addOutputItem(itemId, amount)` / `hasOutputItem(itemId, [amount])` / `consumeOutputItem(itemId, amount)` — 输出物品 CRUD
- `bool canAcceptInputItem(String itemId)` / `acceptInputItem(itemId)` / `hasInputItems(itemId, amount)` / `consumeInputItems(itemId, amount)` — 输入物品 CRUD
- `bool get isBeltBridge` — 是否为物流桥建筑
- **物流桥通道方法**：
  - `String? bridgeItemIdForOutputDirection(String outputDirection)` — 获取该方向通道当前的物品 ID
  - `int bridgeItemCountForOutputDirection(String outputDirection)` — 获取该方向通道的物品数量
  - `bool canAcceptBridgeInputItem(String itemId, String outputDirection)` — 物流桥是否可接收该方向/物品的输入
  - `bool acceptBridgeInputItem(String itemId, String outputDirection)` — 物流桥接收输入
  - `bool consumeBridgeOutputItem(String itemId, String outputDirection)` — 物流桥消费输出
- `int get effectiveWidth` / `effectiveHeight` — 旋转后的有效宽/高（90°/270° 时宽高互换）
- `double get effectiveGridX` / `effectiveGridY` — 旋转后居中的有效网格原点
- `Rect getBounds(double cellSize)` — 建筑在世界坐标的占地矩形
- `bool overlaps(Rect other, double cellSize)` — 是否与给定矩形重叠
- `Map<String, bool> conveyorPortConnections(Iterable<ConveyorBelt> conveyors, {double cellSize = 48.0, double threshold = 30.0})` — 检测各端口是否与给定传送带集合连接，返回 `input_X`/`output_X` → true 的映射

### `ConveyorItemSegment`

表示传送带上的一段物品流（同一种 itemId 的连续填充段）。

| 字段 | 类型 | 说明 |
|------|------|------|
| `itemId` | `String` | 该段物品的 ID |
| `fillCount` | `int` | 填充计数（已填充到的格子位置） |
| `drainCount` | `int` | 排空计数（已排空到的格子位置） |
| `freezeProgress` | `double?` | 冻结的动画进度（用于死胡同平滑过渡，可空） |

**方法**：
- `bool get hasItems` — 该段是否还有有效物品
- `ConveyorItemSegment copyWith({...})` — 复制并部分替换
- `ConveyorItemSegment shifted(int offset, {bool clearFreezeProgress = false})` — 返回偏移后的新段
- `ConveyorItemSegment? clipped(int start, int end, {bool clearFreezeProgress = false})` — 按 [start,end] 裁剪段，无物品返回 null

### `ConveyorBelt`

表示一条传送带实例。

**常量**：`_cellSize = 48.0`

**字段**：
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `String` | 传送带唯一 ID |
| `path` | `List<Offset>` | 传送带路径（网格坐标列表） |
| `itemId` | `String` | 当前主物品 ID（legacy 字段，与 segments 同步） |
| `lastItemId` | `String` | 残留物品 ID（源断开后的旧物品） |
| `itemSegments` | `List<ConveyorItemSegment>` | 物品段列表（新模型） |
| `particles` | `List<Offset>` | 粒子位置列表（用于动画） |
| `flowProgress` | `double` | 流动进度 |
| `itemFillCount` | `int` | legacy 填充计数 |
| `itemDrainCount` | `int` | legacy 排空计数 |
| `isBlocked` | `bool` | 是否阻塞 |
| `forcedDirection` | `String?` | 强制方向 |
| `incomingDirection` | `String?` | 入射方向 |
| `phaseOffset` | `double` | 动画相位偏移 |
| `lastItemFillCount` / `lastItemDrainCount` | `int` | 残留物品填充/排空计数 |
| `deadEndFreezeProgress` | `double?` | 死胡同冻结进度 |
| `lastItemFreezeProgress` | `double?` | 残留物品冻结进度 |

**关键方法**：
- `Offset get start` / `end` — 路径起点/终点的世界像素坐标
- `double get length` — 传送带像素长度
- `double animationProgress(double globalProgress)` — 根据全局进度与相位偏移计算动画进度（取模并处理负值）
- `bool get hasStoppedLastItems` — 末端是否有停滞的残留物品
- `bool get hasLastItems` — 是否存在残留物品
- `int get stoppedLastItemStartIndex` — 停滞残留物品的起始索引
- `int get currentItemFillLimit` — 当前物品填充上限
- `void ensureItemSegmentsFromLegacy()` — 从 legacy 字段重建 `itemSegments`
- `List<ConveyorItemSegment> shiftedItemSegments(int offset, {bool clearFreezeProgress = false})` — 返回偏移并过滤后的段列表
- `List<ConveyorItemSegment> clippedItemSegments(int start, int end, {bool clearFreezeProgress = false})` — 返回裁剪后的段列表
- `void syncLegacyFromSegments()` — 将 `itemSegments` 同步回 legacy 字段，并清理、排序、合并相邻同物品段
- `bool pushSourceItem(String sourceItemId, {int? terminalLimit})` — 从源头推入一个物品到传送带
- `String? outputReadyItemId()` — 返回末端已就绪可输出的物品 ID
- `String? downstreamItemId()` — 返回下游（末端）段的物品 ID
- `bool removeOutputReadyItem()` — 移除末端已就绪的物品
- `bool advanceItemSegments({required bool isDeadEnd, String? activeSourceItemId, int? terminalLimit})` — 推进物品段（死胡同与非死胡同两种逻辑），返回是否发生变化
- `void freezeDeadEndSegments()` — 冻结石胡同中已达极限的段（设置 `freezeProgress = -1.0` 等待渲染器平滑推进）

### `ProjectState`

表示整个项目的运行时状态。

**常量**：`defaultWarehouseItemCount = 99999`（仓库默认初始数量）

| 字段 | 类型 | 说明 |
|------|------|------|
| `buildings` | `List<PlacedBuilding>` | 已放置建筑列表 |
| `conveyors` | `List<ConveyorBelt>` | 传送带列表 |
| `offsetX` / `offsetY` | `double` | 视图偏移 |
| `scale` | `double` | 视图缩放 |
| `warehouseInventory` | `Map<String, int>` | 全局仓库库存（itemId → 数量） |

**方法**：
- `int getWarehouseItemCount(String itemId)` — 获取仓库库存数量，未记录则返回 `defaultWarehouseItemCount`
- `void decrementWarehouseItem(String itemId)` — 仓库取货口输出物品，库存减 1（不低于 0）
- `void incrementWarehouseItem(String itemId)` — 仓库存货口接收物品，库存加 1
