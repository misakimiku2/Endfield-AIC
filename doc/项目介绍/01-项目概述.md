# 01 — 项目概述

## 1.1 项目定位

**Endfield AIC Planner** 是一款基于 Flutter 的桌面/Web 工业规划工具，灵感来自游戏《明日方舟：终末地》中的 AIC（自动化工业控制）系统。用户可以在无限画布上：

- 放置各类生产设备（精炼炉、仓库存取口、物流单元）
- 通过传送带连接设备的输出端口到输入端口，构建完整产线
- 实时仿真生产过程：配方消耗、产物生成、物品沿传送带流动
- 调整仿真速度（0.25x ~ 4x），观察产线阻塞与流通情况

## 1.2 技术栈

| 类别 | 技术 |
|------|------|
| 框架 | Flutter (Dart ≥ 3.1.0) |
| 状态管理 | `provider: ^6.1.1` |
| 矢量图形 | `flutter_svg: ^2.0.9` |
| 数学库 | `vector_math: ^2.1.4` |
| 并发模型 | `dart:isolate`（原生）/ 主线程定时器（Web 回退） |
| 代码规范 | `flutter_lints: ^3.0.1` + 自定义规则 |

## 1.4 运行方式

### 环境准备

```bash
# 安装 Flutter SDK（≥ 3.1.0）
flutter --version

# 拉取依赖
flutter pub get
```

### 启动应用

```bash
# 桌面端（推荐，支持 Isolate 加速仿真）
flutter run -d windows   # 或 macos / linux

# Web 端（自动回退到主线程仿真）
flutter run -d chrome
```

### 静态分析

```bash
flutter analyze
```

### 关键启动流程（`lib/main.dart`）

1. `WidgetsFlutterBinding.ensureInitialized()` — 初始化 Flutter 绑定
2. 提升 `imageCache` 容量至 1000 条 / 200MB（容纳多尺寸缩放图）
3. 设置状态栏样式（深色背景）
4. `DataLoader.loadAll()` — 并行加载三个 JSON 数据库
5. `_precacheAllAssets()` — 预加载所有 PNG（原始 + 7 种缩放尺寸）和 SVG 到缓存，避免首次打开弹窗时的解码延迟
6. 构造 `SimulationEngine` 并 `runApp(EndfieldAICApp(...))`

> **预加载策略**：`Image.asset` 使用 `cacheWidth/cacheHeight` 时内部包装为 `ResizeImage`，其缓存键与原始 `AssetImage` 不同，因此必须按各 UI 实际使用的尺寸（`_itemCacheSizes = [120, 162, 168, 192, 210, 279, 384]`）分别预加载才能命中缓存。

## 1.5 代码规范（`analysis_options.yaml`）

继承 `flutter_lints`，额外启用：

- `prefer_const_constructors` — 优先 const 构造函数
- `prefer_const_declarations` — 优先 const 而非 final
- `avoid_print` — 禁用 `print`（改用 `debugPrint`）
- `prefer_single_quotes` — 优先单引号字符串
