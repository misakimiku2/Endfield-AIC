# 核心功能说明

## 画布系统

### 无限网格
- 支持无限大小的画布网格
- 网格线采用淡灰色 (#b0b0b0)，50% 透明度
- 背景色采用淡灰 (#E4E4E4)
- 单元格尺寸：48 像素

### 视图控制
- **平移**：鼠标中键拖动 / 触摸板双指拖动
- **缩放**：鼠标滚轮 / 触摸板双指捏合
- **旋转**：支持画布旋转（用于调整视角）
- 缩放范围：0.25x ~ 5x

### 设备放置
- 拖拽设备到画布进行放置
- 放置时支持旋转（R 键或 UI 按钮）
- 网格自动吸附
- 碰撞检测（防止设备重叠）

## 物流系统

### 传送带 (Transport Belt)
- **功能**：传输固体物品
- **占地**：1×1 单元格
- **传输速率**：0.5 单位/秒
- **特性**：
  - 支持多个方向（上下左右）
  - 支持转弯（90度转角）
  - 支持推送式传输（物品主动推送到下一段）
  - 传输动画（物品粒子沿路径移动）

### 分流器 (Splitter)
- **功能**：将一条传送带均匀分配到多条（最多3条）分支
- **占地**：1×1 单元格
- **传输速率**：0.5 单位/秒
- **特性**：
  - 支持循环分配模式
  - 可配置各分支的输出比例
  - 自动平衡物品分配

### 汇流器 (Converger)
- **功能**：将多条（最多3条）分支汇流到一条传送带
- **占地**：1×1 单元格
- **传输速率**：0.5 单位/秒
- **特性**：
  - 支持多输入合并
  - 自动处理物品输入顺序
  - 防止物品堆积

### 物流桥 (Belt Bridge)
- **功能**：让两条传送带交叉运输互不干扰
- **占地**：1×1 单元格
- **传输速率**：0.5 单位/秒
- **特性**：
  - 支持立体交叉
  - 不干扰下方传送带的传输
  - 可跨越任意高度差

### 物品准入口 (Item Control Port)
- **功能**：设置允许通过的物品类型与最大数量
- **占地**：1×1 单元格
- **特性**：
  - 可过滤物品类型
  - 可设置通过上限
  - 用于流量控制

## 生产系统

### 精炼炉 (Refining Unit)
- **功能**：使用高温精炼矿物材料
- **占地**：3×3 单元格
- **耗电**：5W
- **容量**：输入50/输出50
- **配方示例**：
  - 源矿 → 晶体外壳（2秒）
  - 蓝铁矿 → 蓝铁块（2秒）
  - 紫晶矿 → 紫晶纤维（2秒）

### 粉碎机 (Shredding Unit)
- **功能**：粉碎各种材料
- **占地**：3×3 单元格
- **耗电**：5W
- **容量**：输入50/输出50
- **配方示例**：
  - 源矿 → 源石粉末（2秒）
  - 蓝铁块 → 蓝铁粉末（2秒）
  - 紫晶纤维 → 紫晶粉末（2秒）

### 配件机 (Fitting Unit)
- **功能**：加工各式零件
- **占地**：3×3 单元格
- **耗电**：20W
- **容量**：输入50/输出50
- **配方示例**：
  - 蓝铁块 → 铁制零件（2秒）
  - 紫晶纤维 → 紫晶零件（2秒）

### 种植机 (Planting Unit)
- **功能**：培育各类普通植物
- **占地**：5×5 单元格
- **耗电**：20W
- **容量**：输入50/输出50
- **配方示例**：
  - 荞花种子 → 荞花（2秒）
  - 柑实种子 → 柑实（2秒）

### 采种机 (Seed-Picking Unit)
- **功能**：采集植物种子
- **占地**：5×5 单元格
- **耗电**：10W
- **容量**：输入50/输出50
- **配方示例**：
  - 荞花 → 荞花种子（2秒）
  - 柑实 → 柑实种子（2秒）

## 仓储存取系统

### 仓库存货口 (Depot Loader)
- **功能**：将物品运送至当地仓库
- **占地**：3×1 单元格
- **特性**：
  - 只能贴靠仓库存取线放置
  - 自动将输入物品存入仓库
  - 支持多种物品类型

### 仓库取货口 (Depot Unloader)
- **功能**：从当地仓库取出物品
- **占地**：3×1 单元格
- **特性**：
  - 只能贴靠仓库存取线放置
  - 可选择要取出的物品类型
  - 支持按需取出

### 协议储存箱 (Protocol Stash)
- **功能**：拥有多个容纳格的储物设备
- **占地**：3×3 单元格
- **耗电**：5W
- **容量**：6个物品格，每格50
- **特性**：
  - 通电状态下可将物品转移至仓库
  - 常用于产线末端

## 仿真系统

### Tick 仿真
- 基于离散时间步（Tick）的仿真
- 每个设备按固定周期处理物品
- 支持暂停/继续/加速

### 传送带仿真
- 推送式传输：物品主动推送到下一段
- 支持物品流动动画
- 处理传输冲突与堵塞

### 生产仿真
- 设备按配方时间处理物品
- 输入/输出缓冲区管理
- 堵塞状态检测

## UI 交互

### 设备选择坞
- 可拖拽的设备选择面板
- 分类显示各类设备
- 点击选择设备进行放置

### 设备详情弹窗
- 点击设备弹出详情
- 显示设备信息（名称、尺寸、耗电等）
- 显示当前配方
- 配置端口连接

### 配方选择
- 在设备详情弹窗中选择配方
- 显示配方详情（原料、产物、时间）
- 自动激活对应端口

### 传送带创建模式
- 拖拽创建传送带
- 实时预览传送带路径
- 支持转弯创建
- 碰撞检测提示

### 浮动操作按钮
- 快捷操作按钮组
- 包括：清空画布、保存项目、加载项目等
