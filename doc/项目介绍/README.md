# 终末地 AIC 工业规划工具 - 项目介绍

## 概述

**终末地 AIC 工业规划工具** (Endfield AIC Planner) 是一款为《明日方舟：终末地》玩家社区开发的高颜值、高性能、跨平台的自动化工业系统规划与模拟工具。

本工具采用 **Flutter (基于 CanvasKit 渲染)** 技术框架，实现网页端（Web）、移动端（Android）及桌面端（Windows）的高效多端共用。

---

## 核心特性

### 1. 视觉设计
- **像素级复刻原版美学**：扁平、硬朗、全直角、带有淡雅投影的高级极简工业风
- **动态设备渲染**：设备图标由程序根据参数实时"拼装"，不依赖静态切图
- **矢量图形支持**：使用 SVG 实现高质量缩放显示

### 2. 性能表现
- **大规模蓝图支持**：支持画布上摆放超过 500 个设备、1000 条传送带
- **帧率优化**：PC 网页端帧率稳定在 60 FPS 以上（利用 CanvasKit 硬件加速）
- **离屏缓存**：实现离屏重绘缓存（Offscreen Picture Caching），确保数百台设备同屏依然满帧

### 3. 系统架构
- **图形与业务逻辑分离**：机器图标与逻辑端口完全解耦
- **数据驱动架构**：支持通过 JSON 数据库扩展物料、配方和设备
- **仿真引擎**：基于 Tick 的生产模拟系统

## 核心模块

### 1. 画布引擎 (Canvas Engine)
- 网格绘制与变换
- 建筑渲染器
- 仿真引擎
- Worker 通信协议

### 2. 物流系统 (Logistics Units)
- 传送带 (Transport Belt)
- 分流器 (Splitter)
- 汇流器 (Converger)
- 物流桥 (Belt Bridge)
- 物品准入口 (Item Control Port)

### 3. 生产设备 (Production Equipment)
- 基础生产：精炼炉、粉碎机、配件机、塑形机、采种机、种植机
- 合成制造：提纯机、反应池、研磨机、封装机、灌装机、装备原件机
- 特殊设备：天有洪炉（息壤合成）

### 4. 仓储存取 (Depot Access)
- 仓库存货口 (Depot Loader)
- 仓库取货口 (Depot Unloader)
- 仓库存取线基段
- 协议储存箱
