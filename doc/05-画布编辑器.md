# 05 — 画布编辑器

> 对应目录：`lib/canvas/`

画布编辑器是项目的交互核心，承载所有用户交互（缩放/平移/旋转/放置/移动/长按/传送带创建）、传送带物品动画驱动，以及通过 `_EditorPainter` 完成全部渲染。

## 5.1 文件清单

```
lib/canvas/
├── building_renderer.dart          通用建筑渲染器
├── canvas_editor.dart              画布编辑器（交互核心，~2900 行）
├── conveyor_create_mode_hud.dart   传送带创建模式 HUD 绘制
├── grid_painter.dart               网格背景绘制
├── sim_protocol.dart               Isolate 通信协议（详见 06-仿真引擎）
├── sim_worker.dart                 计算 Isolate 入口（详见 06-仿真引擎）
└── simulation_engine.dart          仿真引擎主线程侧（详见 06-仿真引擎）
```

> `sim_protocol.dart`、`sim_worker.dart`、`simulation_engine.dart` 三个文件属于仿真引擎，详见 [06-仿真引擎](./06-仿真引擎.md)。

## 5.2 `grid_painter.dart` — 网格背景

绘制画布的网格背景（含旋转、缩放淡出、主次网格线）。

### `GridPainter extends CustomPainter`

| 字段 | 类型 | 说明 |
|------|------|------|
| `offsetX` / `offsetY` | `double` | 画布平移偏移 |
| `scale` | `double` | 缩放比例 |
| `cellSize` | `double` | 单格像素（默认 48） |
| `rotation` | `double` | 画布旋转弧度 |
| `_baseCellSize` | `double` (const) | 48.0 |
| `_fadeStartScale` / `_fadeEndScale` | `double` (const) | 网格淡出区间 0.5 / 0.25 |

**关键方法**：
- `double _gridOpacity()` — 根据缩放在 [0.25, 0.5] 区间线性插值透明度
- `void paint(Canvas canvas, Size size)` — 主绘制：填充背景 → 旋转坐标系 → 计算可见包围盒 → 绘制竖/横网格线（每 8 格为主网格线，加粗）
- `bool shouldRepaint(covariant GridPainter oldDelegate)` — 偏移/缩放/旋转变化时重绘

**依赖关系**：被 `canvas_editor.dart` 的 `_EditorPainter.paint` 实例化调用，作为最底层背景。

## 5.3 `building_renderer.dart` — 通用建筑渲染器

在 Canvas 上绘制建筑本体、端口箭头与放置预览（占位框）。**纯静态方法**的工具类。

### 常量字段

| 字段 | 值 | 说明 |
|------|----|------|
| `_frameStrokeTopBottom` | 3.0 | 上下边框粗细 |
| `_frameStrokeLeftRight` | 1.5 | 左右边框粗细 |
| `_portSize` | 8.0 | 端口方块尺寸 |
| `_frameColor` | `0xFF333333` | 边框色 |
| `_portActiveColor` | `0xFFFFCC00` | 端口激活黄 |
| `_portInactiveColor` | `0xFF666666` | 端口未激活灰 |

### 关键方法

```dart
// 渲染已放置建筑
static void renderBuilding(
  Canvas, Building, gridX, gridY, cellSize, rotation,
  {Recipe? activeRecipe, bool isBlocked, double productionProgress,
   Map<String,int>? portConnections, int detailLevel=2}
)

// 渲染放置/移动预览（碰撞时红色 #FF4444，否则蓝色 #44AAFF）
static void renderPlaceholder(
  Canvas, Building, gridX, gridY, cellSize, opacity,
  {rotation, isBlocked}
)

// 绘制端口三角形箭头（输入口绿色指向内部，输出口黄色指向外部）
static void drawPortArrows(Canvas, Building, w, h, cellSize, {opacity})
```

**端口连接状态值**（`portConnections` 中的值）：
- `0` = 灰色（未连接）
- `1` = 黄色（已连接）
- `2` = 蓝色（预览将连接）

**依赖关系**：依赖 `models/building.dart`、`models/recipe.dart`；被 `canvas_editor.dart` 的 `_EditorPainter._renderBuildingStatic` 与放置预览分支调用（作为非特殊建筑的默认渲染器，特殊建筑如 `RefiningUnit`/`DepotAccess`/`LogisticsUnit` 有各自专用渲染器）。

## 5.4 `conveyor_create_mode_hud.dart` — 传送带创建模式 HUD

在传送带创建模式下，于屏幕四边绘制带流动条纹的黄色边框 HUD，并在错误时闪烁红色提示。

### `ConveyorCreateModeHudPainter`（全静态）

| 字段 | 类型 | 说明 |
|------|------|------|
| `_yellow` / `_red` / `_softEdge` | `Color` (const) | 黄 #FFC400 / 红 #FF3B30 / 软边白 |
| `_spacing` / `_thickness` / `_stripeBand` | `double` (const) | 28 / 10 / 32 条纹几何参数 |
| `_createTextPicture` / `_errorTextPicture` | `PictureInfo?` | 预加载的 SVG 文字图片 |
| `_isError` / `_errorStartTimeUs` | `bool` / `int?` | 错误动画状态 |
| `_flashHalfUs` / `_holdUs` / `_transitionUs` | `int` (const) | 150ms/400ms/500ms 错误动画时序 |
| `_frameColor` / `_frameOpacity` / `_frameSvgBlend` | 静态可变 | 每帧计算的颜色/透明度/SVG 混合系数 |

**关键方法**：
- `static Future<void> init({VoidCallback? onReady})` — 异步加载 `HUD_create_text.svg` 与 `HUD_error_text.svg`
- `static void triggerError()` — 触发错误动画（记录起始微秒时间）
- `static void _updateErrorState()` — 三阶段错误状态机：闪烁(4×150ms) → 保持(400ms) → 过渡回正常(500ms)
- `static void paintHud(Canvas, Size, double phase)` — 主入口：saveLayer 透明度 → 绘制实心边轨 → 顶部 `/` 条纹(向右) → 左侧 `/` 条纹(向上) → 右侧 `\` 条纹(向下) → 绘制含 SVG 文字的创建模块

**依赖关系**：依赖 `flutter_svg`；被 `canvas_editor.dart` 在 `initState` 调用 `init(onReady: _forceRepaint)`，在 `_EditorPainter.paint` 末尾当 `conveyorMode` 为真时调用 `paintHud`；错误时由 `CanvasEditorState._handleTap` 调用 `triggerError()`。

### 5.5.3 `CanvasEditorState` 关键字段

**动画驱动**：

**视图变换（lerp 平滑）**：

- `_cellSize = 48.0` (const)
- `_minScale = 0.25` / `_maxScale = 5.0` (const)

**交互状态**：
- `_hoveredBuilding` — 悬停高亮建筑
- `_placingRotation` — 放置时旋转
- `_beltCtrl` — `TransportBeltController` 实例（传送带创建控制器）

**长按与移动模式**：

- `_movingBuilding` / `_movingRotation` / `_movingOriginalGridX/Y`

**缓存**：

- `_prevBeltItemIds` / `_prevBeltLastItemIds` / `_prevBeltProgressForTick` — 传送带物品/进度跟踪（跨零检测）
- `_repaintTrigger` — 强制重绘计数器

### 5.5.4 关键方法分组

#### 生命周期
- `initState()` — 初始化显示变换 → 创建 `_ticker` → 创建 `_beltCtrl` → `_beltArrowController..repeat()` 并 addListener `_onBeltAnimationFrame` → `_rebuildPortConnectionsCache()` → 初始化各渲染器（TransportBelt/ConveyorHud/RefiningUnit/DepotAccess/LogisticsUnit）
- `didUpdateWidget(oldWidget)` — project 引用变化时同步变换并重建端口缓存；placingBuilding 变化时重置旋转；conveyorMode 切换时 `_forceRepaint` 与 `_beltCtrl.reset()`
- `dispose()` — 释放 ticker/controller

#### 动画驱动
- `void _onTick(Duration elapsed)` — Ticker 回调：长按进度计算（≥1 进入移动模式）→ lerp 平滑 scale/offset/angle（lerpFactor=0.2）→ 全部到位且无长按/移动时停止 ticker 并写回 project
- `void _onBeltAnimationFrame(double globalProgress)` — **传送带物品动画核心**：对每条传送带计算 `animationProgress`，检测跨零（previous>0.5 && progress<0.5）→ 触发 `_tickSingleBeltOnce` → 若库存变化则 `onProjectChanged` + `setState`
- `bool _tickSingleBeltOnce(ConveyorBelt, List<PlacedBuilding>)` — 单条传送带单次推进：判断死胡同/输入建筑/阻塞 → `pushSourceItem` + 消耗源设备输出 → `advanceItemSegments` → 转移输出到建筑或冻结死胡同段

#### 传送带-建筑物品流转
- `bool _canBeltOutputEnterBuilding(ConveyorBelt, PlacedBuilding, String itemId)` — 物流桥/仓库/普通建筑的输入接纳判定
- `String? _beltExitDirection(...)` / `_beltArrivalDirection(...)` / `_directionBetween(...)` — 传送带出入方向推断
- `PlacedBuilding? _findInputBuildingAtCell(Offset)` — 查找格子上对应的输入端口建筑
- `bool _transferBeltOutputToBuilding(ConveyorBelt, PlacedBuilding)` — 将传送带末端物品转移给建筑（物流桥/仓库存货口/普通建筑+自动选配方）
- `void _autoSelectRecipe(PlacedBuilding, String inputItemId)` — 根据输入物品自动匹配配方
- `void _freezeReadyOutputSegments(ConveyorBelt, {required int limit})` — 冻结已就绪输出段
- `String? _getAvailableOutputItemIdForBeltStart(ConveyorBelt)` — 查找传送带起点可用的输出物品
- `bool _consumeOutputItemForBeltStart(ConveyorBelt, String itemId)` — 消耗源设备输出物品
- `int? _findOutputPortIndexAtCell(PlacedBuilding, Offset)` — 查找格子上对应的输出端口索引

#### 坐标变换
- `Offset _screenToWorld(Offset, Size)` — 屏幕坐标逆变换到世界坐标（撤销 translate(center) → 逆旋转 → translate(-center) → translate(+offset) → unscale）
- `Offset _screenToGrid(Offset, Size)` — 世界坐标除以 cellSize 取 floor
- `PlacedBuilding? _getBuildingAt(Offset gridPos)` — 命中测试
- `Offset _inverseRotate(Offset, cosA, sinA)` / `_screenDeltaToWorldDelta(Offset)` — 逆旋转辅助

#### 手势处理
- `void _handleScroll(PointerScrollEvent, Offset localPos)` — 滚轮缩放（以鼠标为锚点，含旋转空间转换）
- `void _handleScaleStart/Update/End(...)` — 双指/单指缩放与平移（含旋转 delta 转换）
- `void _handleTap(Offset, Size)` — 点击分发：放置建筑 / 传送带模式（首次点击空白触发 HUD 错误动画 + toast「请从设备输出端口进行创建」，路径无效时 toast「设备重叠」）
- `void _handleSingleClick(...)` / `_handleRightClick(...)` — 单击选中 / 右键（传送带模式取消）
- `KeyEventResult _handleKeyEvent(FocusNode, KeyEvent)` — ESC（取消移动/退出传送带模式）、R（旋转放置/移动建筑）

#### 长按与移动模式
- `void _startLongPress(Offset, PlacedBuilding)` / `_cancelLongPress()` / `_enterMoveMode()` — 长按 800ms 进入移动模式
- `void startMoveFromDialog(PlacedBuilding)` — 从对话框触发移动
- `void deleteBuilding(PlacedBuilding)` — 删除建筑并移除端口传送带格
- `bool cancelMoveMode()` / `void _placeMovingBuilding(Offset)` — 取消/确认移动
- `void _removePortBeltCells(PlacedBuilding)` — **复杂方法**：移除设备端口上的传送带格，将路径按端口格拆分为多段，处理 lostSource（源断开时物品状态转移）、incomingDirection/forcedDirection 推断、itemFillCount/DrainCount 按段偏移、deadEndFreezeProgress 继承

#### 传送带管理
- `ConveyorBelt? _findBeltAtCell(Offset)` / `bool _isCellOnBuildingPort(Offset)` — 查找/判定
- `List<ConveyorBelt> _findConnectedBelts(ConveyorBelt)` — 递归遍历连通的传送带产线
- `void _showConveyorBeltDialog(ConveyorBelt, Offset)` — 弹出传送带操作对话框（存储单格/整线、收取全部/指定物品）
- `void _removeBeltCell(String beltId, Offset cell)` — 移除单格并按需拆分为两条传送带
- `void _storeBeltLineByIds(Set<String>)` / `_collectAllFromLine(...)` / `_collectItemFromLine(...)` — 整线操作

#### 放置与碰撞
- `bool _checkBuildingCollision(Building, cx, cy, rotation)` — 建筑重叠 + 传送带碰撞（旋转后有效占地，物流桥可重叠直行格）
- `void _placeBuilding(Building, Offset gridPos, {int rotation})` — 放置建筑（碰撞失败 toast「设备重叠」）
- `void _rebuildPortConnectionsCache()` — 重建所有建筑的端口连接缓存
- `void _forceRepaint()` — 清缓存 + 计数器++ + setState

#### build 与渲染入口
- `Widget build(BuildContext)` — `Focus`(键盘) → `MouseRegion`(悬停) → `Listener`(指针信号/按下/移动/抬起/取消) → `GestureDetector`(缩放/右键) → `CustomPaint`(`_EditorPainter`)
- `bool get isCreatingConveyorBelt` / `void finishConveyorBeltCreation()` — 传送带创建状态与完成接口

### 5.5.5 `_EditorPainter extends CustomPainter`

**关键字段**：约 30 个渲染参数（project/dataLoader/cellSize/placingBuilding/placingRotation/mouseGridPos/hoveredBuilding/conveyorMode 及 conveyor 系列/display 变换/portConnectionsCache/长按/移动状态/beltArrowController），以及静态缓存：
- `static final Map<String, ui.Picture> _pictureCache` — 预渲染缓存（key = `"buildingId_rotation_detailLevel_assetVersion_portsHash"`，max 200）

**关键方法**：
- `static void clearPictureCache()` — 清空缓存
- `void paint(Canvas, Size)` — **主渲染流程**（约 1100 行）：
  1. `_computeViewport` 计算可见世界包围盒
  2. `GridPainter.paint` 绘制背景
  3. 应用画布旋转/平移/缩放
  4. LOD 分级（scale<0.35→0, <0.5→1, else→2）
  5. 构建 `fullPathContext`（已确认段+实时段+转角扩展）用于转角纹理
  6. 渲染所有传送带（含动态裁剪分叉点、物流桥隐藏格、视口剔除、临时 clippedBelt 构造）
  7. 渲染传送带预览（有效蓝色/无效红色/悬停高亮）
  8. 渲染物流桥预览
  9. 渲染所有建筑（合并端口状态 actual+preview → 查缓存或录制 Picture → drawPicture；特殊建筑单独绘制 Logo）
  10. 渲染放置预览（含碰撞红色叠加 `_drawBlockedOverlays`）
  11. 渲染移动预览
  12. 渲染悬停白框
  13. 屏幕空间绘制长按圆形进度条
  14. conveyorMode 时绘制 HUD
- `_Viewport _computeViewport(Size)` — 屏幕四角逆变换求世界 AABB
- `bool _isPreviewBlocked(...)` / `Set<Offset> _getGridCells(...)` / `_drawBlockedOverlays(...)` — 碰撞检测与红色叠加
- `bool _isBuildingVisible(...)` / `_isPathVisible(...)` — 视口剔除
- `List<ConveyorItemSegment> _previewItemSegmentsForPath(...)` / `_projectForkSourceSegments(...)` — 预览路径的物品段投影
- `void _renderBuildingStatic(...)` — 分发到各专用渲染器
- `bool shouldRepaint(...)` — 逐字段比较决定重绘

### 5.5.6 `_Viewport`

视口包围盒简单数据类（`minX/minY/maxX/maxY`）。

## 5.6 渲染缓存策略

`_EditorPainter._pictureCache` 以 `buildingId_rotation_detailLevel_assetVersion_portsHash` 为 key 缓存 `ui.Picture`，避免每帧重绘建筑静态部分。端口状态变化（含预览蓝色）会改变 `portsHash` 从而失效缓存。`_forceRepaint` 在资源加载完成时清空缓存强制刷新。

## 5.7 LOD（细节层次）分级

| scale 范围 | detailLevel | 渲染内容 |
|------------|-------------|----------|
| < 0.35 | 0 | 仅建筑外框，无端口 |
| < 0.5 | 1 | 建筑外框 + 端口 |
| ≥ 0.5 | 2 | 完整渲染（含端口箭头、传送带粒子等） |
