# 04 — 数据加载层

> 对应文件：`lib/data/data_loader.dart` + `assets/data/*.json`

## 4.1 DataLoader 类

`DataLoader` 是数据加载器组件，通过 Flutter 的 `rootBundle` 从 assets 中读取三个 JSON 文件，并反序列化为对应的模型对象。它持有三个私有 Map（以字符串 ID 为键），并通过 getter 暴露只读访问。

### 状态字段

```dart
Map<String, Item> _items = {};
Map<String, Recipe> _recipes = {};
Map<String, Building> _buildings = {};
```

### 只读 getter

| Getter | 返回类型 | 说明 |
|--------|----------|------|
| `items` | `Map<String, Item>` | 全部物品（以 id 为键） |
| `recipes` | `Map<String, Recipe>` | 全部配方 |
| `buildings` | `Map<String, Building>` | 全部建筑 |
| `mineralOreItems` | `List<Item>` | `category == 'mineral_ore'` 的物品 |
| `plantItems` | `List<Item>` | `category == 'plant'` 的物品 |
| `usableItems` | `List<Item>` | `category == 'usable'` 的物品 |
| `productItems` | `List<Item>` | `category == 'product'` 的物品 |

### 查询方法

```dart
List<Recipe> getRecipesForBuilding(String buildingId);  // 按 allowedBuildings 过滤
Item? getItem(String id);
Recipe? getRecipe(String id);
Building? getBuilding(String id);
```

### 加载方法

```dart
Future<void> loadAll();          // 并行加载三个数据源
Future<void> loadItems();        // 读取 assets/data/items_db.json
Future<void> loadRecipes();      // 读取 assets/data/recipes_db.json
Future<void> loadBuildings();    // 读取 assets/data/buildings_db.json
```

**`loadAll()`** 使用 `Future.wait` 并行触发三个加载方法：

```dart
Future<void> loadAll() async {
  await Future.wait([
    loadItems(),
    loadRecipes(),
    loadBuildings(),
  ]);
}
```

三个加载方法采用完全一致的模式：
1. 通过 `rootBundle.loadString('assets/data/<file>.json')` 读取 JSON 字符串
2. 用 `json.decode` 解析为 `Map<String, dynamic>`
3. 从中取出顶层 key（分别为 `items` / `recipes` / `buildings`）对应的内层 Map
4. 用 `map` + `MapEntry` 将每个键值对转换为模型对象（调用对应模型的 `fromJson` 工厂构造函数），结果写回私有字段

> **注意**：JSON 顶层的 key（如 `"originium_ore"`）与对象内部的 `id` 字段一致，但 DataLoader 仅使用 value 部分构造模型，键本身并未被使用（模型内部以 `id` 字段作为唯一标识）。

## 4.2 JSON 数据契约

三个 JSON 文件均采用统一的外层结构：

```json
{
  "version": "x.y.z",
  "<主体 key>": {
    "<id>": { ... },
    ...
  }
}
```

### 4.2.1 `items_db.json`（version: "2.0.0"）

顶层结构：`{ "version": "...", "items": { "<id>": { ... }, ... } }`

**单个 item 字段示例**：

```json
"originium_ore": {
  "id": "originium_ore",
  "name": "源矿",
  "category": "mineral_ore",
  "sub_type": "mineral_ore",
  "color": "#FFAA00",
  "icon_svg": "originium_ore_symbol",
  "image_asset_path": "assets/png/Natural Resources/Originium_Ore.png",
  "level": 1
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String | 唯一标识 |
| `name` | String | 中文名称 |
| `category` | String | 大类（`mineral_ore`/`plant`/`usable`/`product`） |
| `sub_type` | String | 子类型（目前与 `category` 取值相同） |
| `color` | String | 十六进制颜色 `#RRGGBB` |
| `icon_svg` | String | SVG 图标标识符 |
| `image_asset_path` | String | PNG 图片相对路径 |
| `level` | int | 等级（整数） |

### 4.2.2 `recipes_db.json`（version: "1.0.0"）

顶层结构：`{ "version": "...", "recipes": { "<id>": { ... }, ... } }`

**单个 recipe 字段示例**：

```json
"refine_origocrust": {
  "id": "refine_origocrust",
  "name": "晶体外壳精炼",
  "allowed_buildings": ["refining_unit_3x3"],
  "process_time_seconds": 2.0,
  "inputs": [
    {"item_id": "originium_ore", "amount": 1}
  ],
  "outputs": [
    {"item_id": "origocrust", "amount": 1}
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String | 配方唯一标识 |
| `name` | String | 配方名称（加载时会被 `Recipe.fromJson` 去掉"精炼"二字） |
| `allowed_buildings` | String[] | 允许该配方的建筑 ID 列表 |
| `process_time_seconds` | double | 处理时间（秒） |
| `inputs` / `outputs` | Array | 输入输出物料数组，每项含 `item_id` 和 `amount` |

### 4.2.3 `buildings_db.json`（version: "1.0.0"）

顶层结构：`{ "version": "...", "buildings": { "<id>": { ... }, ... } }`

**单个 building 字段示例**：

```json
"refining_unit_3x3": {
  "id": "refining_unit_3x3",
  "name": "精炼炉",
  "grid_width": 3,
  "grid_height": 3,
  "color": "#E8751A",
  "category": "basic_production",
  "max_inputs": 4,
  "max_outputs": 4,
  "power_consumption": 5.0,
  "svg_asset": "assets/svg/3x3_unit.svg",
  "logo_asset": "assets/svg/LOGO/Refining_Unit_Logo.svg",
  "ports": {
    "inputs": [
      {"relative_x": 0.167, "relative_y": 1.0, "direction": "down", "port_type": "solid"},
      {"relative_x": 0.5, "relative_y": 1.0, "direction": "down", "port_type": "solid"},
      {"relative_x": 0.833, "relative_y": 1.0, "direction": "down", "port_type": "solid"},
      {"relative_x": 0.0, "relative_y": 0.5, "direction": "left", "port_type": "liquid"}
    ],
    "outputs": [
      {"relative_x": 0.167, "relative_y": 0.0, "direction": "up", "port_type": "solid"},
      {"relative_x": 0.5, "relative_y": 0.0, "direction": "up", "port_type": "solid"},
      {"relative_x": 0.833, "relative_y": 0.0, "direction": "up", "port_type": "solid"},
      {"relative_x": 1.0, "relative_y": 0.5, "direction": "right", "port_type": "liquid"}
    ]
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` / `name` | String | 标识与中文名 |
| `grid_width` / `grid_height` | int | 建筑占用的网格尺寸 |
| `color` | String | 建筑颜色（hex） |
| `category` | String | 建筑类别（`basic_production`/`depot_access`/`logistics_units`） |
| `max_inputs` / `max_outputs` | int | 最大输入/输出端口数 |
| `power_consumption` | double | 功耗 |
| `svg_asset` | String | 建筑本体 SVG 路径 |
| `logo_asset` | String | 建筑 LOGO SVG 路径 |
| `ports.inputs` / `ports.outputs` | Array | 端口定义列表 |

**端口字段**：
| 字段 | 说明 |
|------|------|
| `relative_x` / `relative_y` | 相对坐标 0~1 |
| `direction` | `up`/`down`/`left`/`right` |
| `port_type` | `solid` 或 `liquid` |

## 4.3 资源组织方式

`assets/` 目录采用按类型 + 用途分层的方式组织，并在 `pubspec.yaml` 的 `flutter.assets` 段落中显式声明每个子目录：

```
assets/
├── data/                          # 三个数据 JSON 文件
│   ├── buildings_db.json
│   ├── items_db.json
│   └── recipes_db.json
├── svg/                           # 矢量图标与建筑 SVG
│   ├── LOGO/                      # 建筑 LOGO
│   │   ├── Depot_Loader_logo.svg
│   │   ├── Depot_Unloader_logo.svg
│   │   └── Refining_Unit_Logo.svg
│   ├── 3x3_unit.svg               # 精炼炉基础单元
│   ├── Belt_Bridge.svg            # 物流桥
│   ├── Depot.svg / Depot_icon.svg # 仓库存取口
│   ├── Converger.svg / Splitter.svg / Directional.svg
│   ├── Transport_Belt_Move.svg / Transport_Belt_rotate.svg / Transport_LOGO.svg
│   ├── Item_Control_Port.svg
│   ├── Mineral_Ore_icon.svg / Plant_icon.svg / Products_icon.svg / Usable_Items_icon.svg
│   ├── Recipe_button.svg / Collect_button.svg / Collect_A_button.svg
│   ├── HUD_create_text.svg / HUD_error_text.svg
│   ├── information_BG.svg / objective_case.svg / dialog_track.svg
│   ├── liquid.svg / liquid_import.svg / liquid_export.svg / liquid_icon_switch.svg
│   ├── add.svg / Move.svg / No.svg / recycle.svg / pointer.svg
│   └── interface.SVG / rect79.svg
└── png/                           # 位图资源，按用途分子目录
    ├── AIC Products/              # 工业产品图（如 Aketine_Powder、Steel、Xiranite 等）
    ├── Natural Resources/         # 天然原料图（如 Originium_Ore、Buckflower、Citrome 等）
    └── window/                    # UI 窗口元素（实际存放 .svg 文件）
        ├── Close_button.svg
        ├── endfield-industries.svg
        ├── endfield-logo-zh.svg
        └── 弹窗设计.svg
```

### `pubspec.yaml` 中的资源声明

```yaml
flutter:
  uses-material-design: true
  assets:
    - assets/data/
    - assets/svg/
    - assets/svg/LOGO/
    - assets/png/window/
    - assets/png/AIC Products/
    - assets/png/Natural Resources/
```

**组织特点**：
- **JSON 数据**集中在 `assets/data/`，由 `DataLoader` 统一加载。
- **SVG 矢量资源**用于建筑外观、LOGO、UI 图标、HUD 文本等。
- **PNG 位图资源**按"产品 / 原料 / UI 窗口"三类分目录存放，文件名采用下划线命名（如 `Originium_Ore.png`），路径与 `items_db.json` 中的 `image_asset_path` 字段对应。
- 注意 `assets/png/window/` 内实际存放的是 `.svg` 文件（弹窗设计等），目录命名与实际文件类型不完全一致。

## 4.4 字段映射对照表

| JSON 字段（snake_case） | 模型字段（camelCase） | 所属模型 |
|--------------------------|----------------------|----------|
| `id` | `id` | Item / Recipe / Building |
| `name` | `name` | Item / Recipe / Building |
| `category` | `category` | Item / Building |
| `sub_type` | `subType` | Item |
| `color` | `color`（hex → `Color`） | Item / Building |
| `icon_svg` | `iconSvg` | Item |
| `image_asset_path` | `imageAssetPath` | Item |
| `level` | `level` | Item |
| `allowed_buildings` | `allowedBuildings` | Recipe |
| `process_time_seconds` | `processTimeSeconds` | Recipe |
| `inputs` / `outputs` | `inputs` / `outputs`（`List<RecipeIO>`） | Recipe |
| `item_id` / `amount` | `itemId` / `amount` | RecipeIO |
| `grid_width` / `grid_height` | `gridWidth` / `gridHeight` | Building |
| `max_inputs` / `max_outputs` | `maxInputs` / `maxOutputs` | Building |
| `power_consumption` | `powerConsumption` | Building |
| `svg_asset` | `svgAssetPath` | Building |
| `logo_asset` | `logoAssetPath` | Building |
| `ports` | `ports`（`PortsLayout`） | Building |
| `relative_x` / `relative_y` | `relativeX` / `relativeY` | PortDefinition |
| `direction` | `direction` | PortDefinition |
| `port_type` | `portType` | PortDefinition |
