# 汇流器（Converger）全面重构修改总结

## 修改日期
2026-06-22

## 修改背景

汇流器（Converger）是与分流器功能完全相反的物流工具：3条输入传送带汇流至1条输出传送带。此前汇流器仅有数据定义（ConvergerConfig、buildings_db.json）和渲染注册，缺少仿真逻辑、弹窗面板、模型字段等核心实现。

### 用户需求

1. **功能实现**：汇流器支持最多3条分支传送带的物品汇流至1条输出传送带
2. **端口定义**：输入端为左、上、右三个方向，输出端为下方
3. **处理速度**：0.5单位/秒，与分流器一致
4. **排队机制**：FCFS（先到先得），基于物品到达传送带末端的时间戳序号处理
5. **等待机制**：输出带满时物品进入缓冲，缓冲满后输入端阻塞
6. **传送带创建约束**：从汇流器格子只能向下（输出端方向）创建传送带

#### FCFS（先到先得）机制

汇流器采用 FCFS 排队机制，而非循环分配：

1. **到达序号分配**：当物品到达传送带末端（`outputReadyItemId()` 返回非空）时，`_findEarliestArrivalConvergerDirection` 为该方向分配递增序号（`_convergerArrivalCounter++`），存入 `convergerArrivalTimestamps`
2. **优先处理**：每次处理时选择序号最小（最早到达）的方向，该方向的物品被推送到输出带或放入缓冲
3. **等待排队**：非最早到达方向的物品在传送带末端冻结等待，待轮到自己时再处理
4. **序号清理**：物品被取走后清除该方向的到达序号；物品不再在末端时自动清理过期序号

#### 门控机制

`_canBeltOutputEnterBuilding` 汇流器分支：只要存在输出传送带就返回 true，允许物品到达传送带末端排队等待 FCFS 处理。实际的处理能力由 `_transferBeltOutputToBuilding` 中的 FCFS 逻辑决定，而非由门控提前阻断。这样所有输入方向的物品都能到达末端参与 FCFS 排序。

#### 仿真架构

- 汇流器状态由主线程管理，Isolate 跳过覆盖（`if (pb.isBeltBridge || pb.isSplitter || pb.isConverger) continue;`）
- 推送式架构：汇流器从输入传送带拉取物品后直接推送到输出带，不经过内部生产缓冲
- 缓冲机制：输出带满时物品暂存缓冲（最多1个），缓冲满后输入端传送带阻塞

### 4. 传送带多输入端口吸附修复

**文件**: `transport_belt.dart`

#### 问题根因

1x1建筑所有端口的 `gridPosition` 经 `floor()` 后映射到同一格子坐标，`_findPortAtCell` 始终返回第一个匹配的端口（left），导致传送带只能从左侧进入汇流器，上方和右侧输入端口无法使用。

#### 修复方案

**`_findPortAtCell`**：新增 `incomingDirection` 参数，当多个端口在同一格子时，优先匹配方向与来向一致的端口。

**`_findPath`**：当建筑有多个输入端口在同一格子时（如汇流器的 left/up/right），遍历所有输入方向尝试寻路，选择第一个可达的路径，而非只使用第一个端口的方向。

**终点截断保护**：当新传送带的终点是建筑输入端口格子时（`isEndCellInputPort`），如果匹配到的旧传送带终点也在同一格子（`isLastCellOfOldBelt`），则跳过截断。这允许多条传送带终点在同一个输入端口（如汇流器的3个输入端口在同一格子）。

### 5. 汇流器弹窗面板

**新建文件**: `building_converger_panel.dart`

- 等轴测3D视图，绿色主题色（`#49B675`）
- 3条输入轨道（left/up/right）：箭头向中心流动
- 1条输出轨道（down）：箭头向远端流动
- 轨道状态：0=未连接(灰), 1=正常(绿), 2=堵塞(红)
- 物品动画：从输入格 → 中心 → 输出格（按循环顺序分配）
- 输出端堵塞时输入端也显示堵塞状态
- 不显示电源开关和资源面板

#### 方向映射

汇流器弹窗中 left/right 方向与屏幕坐标的映射与分流器一致：
- left 映射到 +x（屏幕左下）
- right 映射到 -x（屏幕右上）
- up 映射到 -y（屏幕左上）
- down 映射到 +y（屏幕右下）

## 传送带创建约束

汇流器输出端口只有 down，`_computeAllowedDirectionsForBuilding` 自动计算允许方向为 `{down}`，BFS 第一步只允许 down 方向，无需额外修改即可实现方向约束。

## 验证要点

1. 单输入场景：1条输入带 → 汇流器 → 1条输出带，物品正常流动
2. 双输入场景：2条输入带 → 汇流器 → 1条输出带，按 FCFS 顺序处理
3. 三输入场景：3条输入带 → 汇流器 → 1条输出带，三个方向按到达顺序处理
4. 输出带阻塞：输出带满时，物品进入缓冲，缓冲满后输入端阻塞
5. 传送带创建：从汇流器格子只能向下创建传送带
6. 传送带吸附：从上方/右方/左方创建传送带到汇流器时，正确连接到对应输入端口
7. 多条输入带终点共存：3条传送带终点均在汇流器格子，互不截断
8. 弹窗面板：正确显示3输入1输出的等轴测3D视图
9. SVG 渲染：汇流器图标正确显示，无 BG 背景遮挡
