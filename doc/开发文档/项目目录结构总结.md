### 模块职责说明

| 模块 | 职责 |
|------|------|
| `pages/` | 页面级别的 UI 组合，目前仅有编辑器主页面 |
| `canvas/` | 核心画布引擎，负责网格绘制、建筑渲染、仿真运算及 Worker 通信 |
| `models/` | 数据模型层，定义建筑、物品、配方、项目等核心数据结构 |
| `data/` | 数据加载层，从 JSON 静态文件加载设备/物品/配方数据 |
| `widgets/` | 可复用的 UI 组件，包括设备坞、弹窗、浮动按钮等 |
| `AIC/` | AIC 设备逻辑模块，按设备类别分目录组织（物流、生产等） |
