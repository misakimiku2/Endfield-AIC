# 09 — UI 组件层

> 对应目录：`lib/widgets/` + `lib/pages/`

UI 组件层负责所有用户可见的界面元素：编辑器主页面、建筑详情弹窗、传送带弹窗、各设备专用面板、底部设备栏、浮动按钮等。

## 9.2 `pages/editor_page.dart` — 编辑器主页面

应用主入口页面，承载画布编辑、设备放置、传送带创建、蓝图导入导出与仿真驱动的整体编排。

### `EditorPage`（StatefulWidget）

接收 `DataLoader` 与 `SimulationEngine`，构建项目状态并驱动仿真。

### `_EditorPageState`（mixin `TickerProviderStateMixin`）

**管理状态**：
- `_placingBuilding` — 放置中的设备
- `_selectedBuilding` — 选中设备
- `_conveyorMode` — 传送带模式
- Toast 动画控制器

**整体布局**（`Scaffold` → `Focus` → `Column`）：

1. **`_buildToolbar()`**（40px 顶部工具栏）：标题"AIC 规划工具"、`_speedControl` 0.25x~4x、导出/导入按钮
2. **`Expanded` + `Stack`**：
   - `Positioned.fill` → `CanvasEditor`（核心画布，持有 `_canvasKey`）
   - `Positioned(right:0,bottom:0)` → `FloatingActionButtons`（传送带/旋转）
   - `Positioned(left:0,right:0,bottom:0)` → `EquipmentDock`（底部设备栏）
   - 条件层 → 错误 Toast（`FadeTransition`，红色圆角胶囊，位于 bottom:124）
3. **`_buildStatusBar()`**（24px 底部状态栏）：设备数、传送带数、缩放百分比、当前模式提示

**键盘绑定**：
- ESC：取消/完成传送带
- Ctrl+R：旋转画布
- R：旋转设备
- E：切换传送带模式
- 1~0：选择 dock 设备（`_dockOrder` 7 项）

**关键回调**：
- `_onDockBuildingSelected`、`_onBuildingPlaced`、`_cancelPlacement`、`_onBuildingTapped`（弹出 `BuildingDetailDialog`）、`_setDepotOutputItem`、`_toggleConveyorMode`、`_rotateCanvas`、`_exportProject`/`_importProject`/`_applyImportData`、`_handleKeyDown`、`_showErrorToast`

## 9.3 `widgets/building_detail_dialog.dart` — 建筑详情弹窗（统一入口）

点击已放置建筑时弹出的统一详情窗口，根据建筑类型分发到不同子面板。

### `BuildingDetailDialog`（StatefulWidget）

提供静态 `show()` 方法。负责窗口信息栏、电源开关、左侧资源面板（4 标签物品网格）、右侧子面板分发。

### `_BuildingDetailDialogState`

**管理状态**：
- `_resourceTabIndex`（0~3 对应 植物/矿物/可用物品/产物）
- `_isAddMode`（仓库取货口的"添加模式"）
- `_selectedOutputItemId`
- 滚动条显隐与拖拽
- SVG logo 加载（含物流桥去除 BG 背景、统一白色填充）
- 物品图片预缓存（`ResizeImage` 279×279）

**类型判定 getter**：`_isDepotUnloader`、`_isDepotLoader`、`_isLogisticsBridge`

### 弹窗结构

`Dialog`（透明背景）→ `LayoutBuilder` → `Container`（宽度 clamp 1280~1460，高 720，圆角 16，深色 `0xFF252525`）→ `Stack`：

1. `DialogBackgroundPattern`（右上角 endfield-industries logo 水印）
2. `Column`：
   - `_buildWindowInfoBar()`（高 77）：logo + 名称 + 耗电功率（物流桥/仓库不显示功率）+ 关闭按钮
   - `_buildSeparator()`
   - 非物流桥时显示 `_buildPowerSwitch()`（开/关滑动开关，控制 `isPaused`）
   - `Expanded` → `Padding` → `Row`：
     - 非物流桥：左侧 `_buildResourcePanel()`（440×520，含 4 标签 `_buildTabBar` + 4 列网格 `_buildGridArea` + 自定义滚动条 `_buildGridScrollbar`）
     - 右侧 `Expanded` 根据 building.id 分发：`DepotUnloaderPanel` / `DepotLoaderPanel` / `LogisticsBridgePanel` / `DefaultSynthesisPanel`

**网格区**：采用 `NeverScrollableScrollPhysics` + `Listener` 拦截滚轮自定义滚动，滚动条 800ms 后淡出，支持拖拽。

### 关键回调

`onMove`、`onDelete`、`onInventoryChanged`、`onOutputItemSelected`

## 9.4 `widgets/building_synthesis_panel.dart` — 合成设备面板

默认合成设备（如 `refining_unit_3x3`）的详情面板。

### `DefaultSynthesisPanel`（StatefulWidget）

**布局**：顶部移动/收纳按钮 + 液体模式开关；中部 `SynthesisGrid`×2 + `ProcessingIndicator` + 进度条；底部当前配方信息条 + `CollectAllButton`。

**`_DefaultSynthesisPanelState` 关键状态**：
- `_isLiquidMode`
- `_simTimer`（100ms 刷新）
- `_loadLiquidSwitch` 预生成 4 种 SVG 状态
- `_hasConnectedOutputBelt` 判断是否连接输出传送带（影响收取按钮启用阈值 ≥2）

### `RecipeListDialog`（StatefulWidget）

960×560 配方选择弹窗，2 列网格，自定义滚轮滚动，`RecipeListItem` + `onPin` 切换 `activeRecipeId`。

### 关键约束（来自项目记忆）

- "全部收取"按钮在连接输出传送带且正常流通时，`totalOutputCount ≤ 1` 禁用（物品立即被传送），`≥ 2` 启用（传送带阻塞，物品堆积）
- 未连接传送带时，`totalOutputCount > 0` 启用
- 这避免了生产速度与输出速度匹配时按钮闪烁

## 9.6 `widgets/building_logistics_bridge_panel.dart` — 物流桥面板

物流桥 `belt_bridge_1x1` 的详情面板，渲染两条等轴测交叉轨道（Track A 30°、Track B 150°）及物品流动动画。

### `LogisticsBridgePanel`（StatefulWidget）

**布局**：左侧文字说明 + 物流速度，右侧 `Stack` 渲染两条轨道与物品。

### `_LogisticsBridgePanelState`（mixin `TickerProviderStateMixin`）

- `_arrowController` 循环动画
- `_spawnTimer` 每 1.5s 生成物品动画
- 通过 `_isTrackConnected`/`_pickItemIdForTrack`/`_findBeltDirectionAtBridge`/`_getBeltDirectionAtIndex`/`_directionBetween` 检测穿过桥格子的传送带方向并取物品 ID

### `_BridgeTrackPainter`（CustomPainter）

等轴测投影 `_project(x,y,z,center)`（cos30/sin30），绘制：
- 顶面、前方面板（z=-10 深度）
- 渐变着色器
- 长边边框
- 3 个错相箭头流动动画
- 区分 `_BridgeTrackType.a`/`b`

### 轨道渲染层次（Stack，从下到上）

1. Track B 的 `CustomPaint`（`_BridgeTrackPainter` type=b）
2. Track B 的物品 widgets（`_buildItemWidgetsForTrack(1)`）
3. Track A 的 `CustomPaint`（type=a，遮挡 Track B 物品形成交叉立体感）
4. Track A 的物品 widgets（最上层）
5. `_buildTrackEndSlots`：4 个端点物品格（`_buildSlotWidget`，含 level 渐变 SVG）

**物品位置**：`x = centerX + travel*cos(angle)`，`y = centerY + travel*sin(angle)`，两端 `_fadeRatio=0.35` 边缘淡出。

**常量**：`_trackLength=480`、`_trackWidth=54`、`_itemSize=40`、`_slotSize=96`、`_trackAngleA=π/6`、`_trackAngleB=5π/6`、`_fadeRatio=0.35`

## 9.7 `widgets/conveyor_belt_dialog.dart` — 传送带弹窗

点击传送带时弹出的详情窗口，渲染水平轨道动画、物品流动、产线物品网格与收取按钮。

### `ConveyorBeltDialog`（StatefulWidget）

提供静态 `show()`。包含信息栏、收纳/收纳整条产线按钮、文字说明、轨道区、物品网格区、全部收取按钮。

### `_ConveyorBeltDialogState`（mixin `TickerProviderStateMixin`）

- `_arrowController`（2s 循环）
- `_spawnTimer`（1.5s 生成物品）
- `_simTimer`（100ms 同步状态）
- `_distinctItemIds` 去重产线所有物品
- `_spawnItem` 循环播放物品动画

### `_ItemSlot`（StatefulWidget）

单个物品格 + 单独收取按钮，hover 缩放 1.08 + tooltip。

### `_SingleCollectButton`（StatefulWidget）

白色 `Collect_A_button.svg` + "收取"文字，hover 灰色预览。

### `_ConveyorTrackPainter`（CustomPainter）

**纯水平**轨道（无等轴测投影），与物流桥 `_BridgeTrackPainter._drawTrackA` 对应：
- 顶面 4 顶点：`p1~p4` 为以 center 为中心的水平矩形（halfLen×halfWidth）
- 顶面渐变 `ui.Gradient.linear`：active 时 `0x00E88A11 → 0xAAFFB82B → 0xAAFFB82B → 0x00E88A11`，inactive 时灰色系
- 边框渐变同步：`0x00FFBB33 → 0xDDFFD266`
- 箭头：3 个错相 1/3，`arrowX = center.dx - halfLen + t*trackLength`，三角形 `(arrowX+5.5, center.dy)` / `(arrowX-4.5, ±3.5)`，两端淡出
- 物品动画：`travel = (progress-0.5)*_trackLength`，`x = centerX + travel`，`y = centerY`，两端淡出

**物品网格区**：空传送带显示 1 个灰色空格；有物品时按 `_distinctItemIds` 横向排列多个 `_ItemSlot`。

**常量**：`_trackLength=480`、`_trackWidth=54`、`_itemSize=40`、`_slotSize=96`

## 9.16 关键设计模式

1. **弹窗统一分发**：弹窗统一通过 `BuildingDetailDialog.show` 分发，按 `building.id` 选择子面板，避免在 `EditorPage` 中硬编码类型判断。

2. **三种轨道渲染风格**：
   - 物流桥等轴测双轨（`_BridgeTrackPainter`）
   - 传送带水平单轨（`_ConveyorTrackPainter`）
   - 合成设备多端口连接器（`TrackJointsPainter`）
   
   均使用 `ui.Gradient.linear` 两端淡出 + 错相箭头动画。

3. **物品流动动画统一模式**：`AnimationController` + `CurvedAnimation(easeInOutCubic)` + 边缘 `ShaderMask`/`Opacity` 淡出，由库存/数量变化驱动生成（`_maybeCreateItemAnimations`/`_spawnItem`）。

4. **SVG 背景字符串替换**：SVG 背景大量使用字符串替换实现 hover 反色与 level 渐变，避免重复解析。

5. **桌面端滚动一致性**：滚动区域统一采用 `NeverScrollableScrollPhysics` + `Listener` 拦截滚轮 + 自定义滚动条，保证桌面端体验一致性。
